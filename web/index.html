重试失败步骤

任务、项目快照和已有成功方案不变。只重试这一步，最多三次尝试；不会自动重试或规避服务限制。每次记录都会保留。

确认方案并生成 Diff

只发送当前任务、这份实施草案和重新读取的上下文，不发送其他候选原文。长草案需人工精简，不会自动截断。

支持手动传递或指定网页；选择手动不会自动发送。Ollama 目前可参与提案和融合，尚未接入代码执行闭环。网页请使用独立新会话，遵守其服务规则。

批准 Diff 后的验证项目

验证脚本在临时副本运行，仍具有本机进程权限，不等于容器隔离。未选择脚本时不会声称测试通过；失败沿用回滚和有限重试，每份新 Diff 都需重新审核。

连接与使用指南
连接浏览器扩展
  1. 保持本地工作台服务运行。
  2. 在扩展管理页开启开发者模式，加载源码中的 browser-extension 文件夹。
  3. 打开并登录 AI 聊天网页，刷新后等待“AI 页面就绪”。
  4. 选择“浏览器扩展”；多个页面就绪时，选择本轮“执行网页”。
固定服务地址：http://127.0.0.1:5000。检测本地服务。页面就绪不代表账号额度可用。
手动传递
复制提示词给模型，将完整回复粘贴回工作台。网页回传失败时，也可展开“手动导入回复”。
对话与草稿
左侧按标题搜索最近或归档对话。本轮结束后在“继续追问”发送下一轮。未发送的任务、追问和手动回复文本保存在当前浏览器，按项目和轮次隔离；删除对话会清除对应草稿。清空输入框即可清除该草稿。草稿不会自动发送。
更新与审核
更新后重新构建并重启本地服务，再刷新工作台。扩展代码有更新时，重新加载 OpenBrowser Bridge 并刷新 AI 网页。会话会恢复，中断任务暂停，旧批准不会自动执行。
模型会收到任务与相关上下文。文件修改须批准 Diff；验证脚本仍具有本机进程权限，不等于容器隔离。
Alt + N 新建任务；/ 搜索文件；Enter 发送；Shift + Enter 换行。顶部可收起两侧边栏。
